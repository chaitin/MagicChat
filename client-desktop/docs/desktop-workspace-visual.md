# 桌面工作区视觉首版

本版借鉴 Buzz 的导航与内容分层，使用即应现有主题和真实聊天组件实现。

## 已实现范围

- 导航按钮改为图标与文字组合，选中态使用低饱和强调色；macOS 保持既有原生控制键空间。
- 导航栏及红绿灯区域使用同一浅绿色，列表栏使用更浅的底色，两栏之间保留细分隔线。
- 聊天、通讯录、项目统一列表栏、标题、筛选和内容面板层级，默认列表宽度为 280px，窄窗口分别使用 236px、216px。
- 会话选中态只使用背景强调，不增加左侧边缘；键盘焦点提示继续保留。
- 全局搜索增加 `expanded` 入口形式，聊天侧栏展示文字搜索按钮，搜索协议和结果处理保持不变。
- 主聊天使用独立内容面板，统一标题分隔线、消息气泡、输入区及发送按钮。
- 配色使用现有主题的语义变量，采用 OKLab 混色，避免与中性色混合时出现色相偏移。
- 样式集中在 `src/renderer/styles/desktop-workspace.css`；视觉类不承担业务状态。

本版未实现可调整侧栏宽度、话题并排、全局前进后退、文档搜索和任务搜索。
原有话题抽屉、会话路由、虚拟列表、草稿及消息处理逻辑继续使用。
既有 WeUI OpenSpec 计划未在本版标记完成，后续实施前应协调其视觉要求。

## 验证记录

- `pnpm check`：格式、ESLint、TypeScript 与 Renderer 边界检查。
- Vitest：现有测试及新增的完整搜索入口键盘打开、会话选择测试。
- 生产构建使用 512 MiB V8 堆上限和 `nice -n 10`，并执行 `pnpm verify:build`。
- 通过本地示例数据挂载真实组件，在浏览器中检查 1280×820、1024×640、760×560 的浅色与深色呈现；额外检查最小窗口的 120% 文字缩放。
- 人工检查搜索弹窗、搜索选择、示例消息发送、会话名称截断和窄窗口输入工具栏。

浏览器预览不加载生产认证或 DesktopBridge，示例消息只保留在页面内存中，不属于真实发送验收。
桌面开发版已通过 `pnpm dev` 启动，本轮修改通过 Vite 热更新加载。
原生窗口自动化缺少系统权限，因此本轮没有完成 macOS 原生窗口拖拽、系统缩放、真实聊天或 Windows/Linux 真机验收。

## 跨端影响

仅修改 Desktop Renderer；Server、Web、Mobile、Main、Preload 和共享协议不受影响。
不新增依赖、数据迁移或发布协议变更。
