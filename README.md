# 即应

[主页](https://jiying.chat/) · [在线体验](https://app.jiying.chat/) · [私有化部署](https://docs.jiying.chat/)

> 让 AI 真正成为数字员工。

即应是 AI 时代的团队协作入口。

即应是一款开源的即时通讯工具，将消息、知识、任务彼此连接，让 Agent 彻底融入工作流，使 AI 真正成为数字员工。

即应提供完整的团队协作能力：群组聊天、项目推进、任务分配、目标跟踪与实时协作文档，让沟通与执行在同一个空间完成。同时，即应内置了能够自然接入相关流程的 AI 智能体，可以自动整理上下文、跟进项目进展、沉淀知识；开放的自定义能力，让每个人都能轻松定义专属智能体，完成更多定制化工作。

即应希望 AI 不是与工作割裂的聊天机器人，而是能接手实际流程的数字员工——沟通、项目、时间、文档，处处替你分担；团队进展一目了然，人的精力回归真正重要的判断与创造。

## 当前能力

### 团队沟通

- 用户私聊、群聊和应用会话，以及从消息派生的话题讨论
- 文本、Markdown、图片、文件、语音、选择、对象卡片和图表消息
- 回复、转发、撤回、表情回应、`@` 提及与消息搜索
- 会话置顶、免打扰、未读状态、群公告和公开/私有群管理
- 基于 WebSocket 的消息、在线状态和通讯录实时同步

### 项目协作

- 个人项目和团队项目，可将项目关联到群聊
- 任务状态、优先级、负责人、标签、起止日期和提醒
- 列表、看板、日历和甘特图等任务视图
- 任务活动记录、评论和定时提醒
- 项目成员管理与文档工作区
- 基于 Tiptap、Yjs 和 Hocuspocus 的多人实时协作文档

### AI 助手

- 以独立应用身份通过 WebSocket 接入即应，而不是嵌入服务端进程
- 使用会话、发送者、项目候选和授权候选等服务端可信上下文处理请求
- 在授权用户的可见范围内查询联系人、应用、群聊、会话、项目和任务
- 可回复当前会话，也可在用户明确授权后代发消息、创建群聊或管理任务
- 支持文本、选择、文件、对象卡片和图表等结构化交付形式
- 支持 Anthropic Messages 兼容模型、MCP 工具以及长会话上下文压缩
- 提供受公网地址约束的 HTTP 工具，以及只读 MySQL、PostgreSQL 查询工具

### 应用与企业管理

- 用户可创建和管理应用，通过应用 WebSocket 协议接入工作空间
- 密码、邮箱验证码和第三方身份提供商登录
- 后台管理用户、应用、登录方式、企业信息和运行状态
- S3 兼容对象存储，区分公开、私有和临时文件
